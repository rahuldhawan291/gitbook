# Index

## Overview

Hey! I'm [Rahul](https://www.linkedin.com/in/rahuldhawan291/), a Senior Security Engineer with over 6 years of hands-on experience in offensive security, infrastructure hardening, and application security. I earned my [**OSCP certification**](https://www.credential.net/f6a1d21e-7d1d-4eed-81a4-bcee9c794e6a) in **2024** after months of rigorous practice, late-night enumeration loops, and a lot of trial, error, and persistence.

This space is a personal documentation of my learning journey through various **Proving Grounds Practice and Hackthebox** [**OSCP-style** machines.](https://docs.google.com/spreadsheets/d/18weuz_Eeynr6sXFQ87Cd5F0slOj9Z6rt/edit?gid=487240997#gid=487240997) Each machine listed here follows a practical exploitation chain from initial foothold to privilege escalation with clear, concise notes focused on:

* Real-world misconfigurations
* Manual enumeration techniques
* Exploit methodology with minimal tooling
* Privilege escalation paths mapped to OSCP exam patterns

Whether you're preparing for the OSCP, brushing up your pentesting skills, or exploring Windows privilege escalation in-depth — I hope these notes help you as much as writing them helped me.
